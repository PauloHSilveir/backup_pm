🎯 O QUE É ESTE PROJETO?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Implementação de um algoritmo híbrido (BRKGA + Busca Local) para resolver o
problema ALWABP (Assembly Line Worker Assignment and Balancing Problem).

Problema: Otimizar linhas de produção considerando trabalhadores heterogêneos
Objetivo: Minimizar o tempo de ciclo da linha

   $ pip install numpy
